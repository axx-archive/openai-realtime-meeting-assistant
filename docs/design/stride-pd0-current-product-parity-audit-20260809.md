# STRIDE PD0 current-product surface, parity, and legacy audit

Observed 2026-08-09. This is a read-only inventory of the current repository and existing evidence. It does not change the canonical plan, declare PD0 complete, or treat a registered route as first-class product quality.

## Verdict: REVISE

The current product has substantial, tested web and native-iPhone capability, especially the private voice/chat/meeting/work system and the default-off W2 identity, organization, Work Record, and network controls. It is not yet the reconciled three-expression product required by PD0:

1. Native iPad is configured as a supported device but locked to portrait and uses the phone stack/sheet composition. There is no size-class shell, Split View/Stage Manager contract, keyboard command system, pointer/context-menu system, cross-app drag/drop, or real-iPad evidence.
2. Public Workspace, governed public Work Objects, public Workstream/Observe/Save, Explore, public organization/workspace/agent profiles, moderation/appeal, and public collaboration are planned contracts, not current first-class surfaces.
3. Network Search/contact code exists, but W6 remains `deterministic_verified_external_qualification_waiting`; the real five-person/two-reviewer cohort, legal/privacy judgments, and activation remain external.
4. Loading/empty/error treatment is present surface-by-surface, but offline, reconnect, account/session revocation, authority loss during interaction, and cross-surface continuation do not have a complete rendered parity matrix.
5. Web and native currently express different information architectures. Some differences are useful platform expression; others are overlapping shell generations that need an explicit migration/removal gate.
